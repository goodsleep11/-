# 计算机网络实验书

一个沉浸式计算机网络实验 Web 原型。入口像一本书被打开，进入后可以切换 12 个旗舰交互实验，并浏览完整大学计算机网络实验目录。

## 已完成

- 书本打开式入口和双页实验书界面
- 12 个可播放、可暂停、可调参、可长按解析的旗舰实验
- Canvas 高分屏渲染，减少整体 DOM 变形造成的画面发糊
- 画布内视角拖拽、滚轮缩放和一键回正
- 鼠标悬浮热点提示、热点高亮和长按知识点解析
- 真实实验误差/异常监测：分片、广播噪声、BDP、SNR、CRC、ARQ、DHCP/NAT、ICMP 等
- 右侧实验小手册，给出正确观察步骤和记录建议
- 固定“大学知识”按钮，可随时查看协议字段、公式、工程提醒和误区
- 桌面与移动端响应式布局

## 旗舰实验

1. 协议栈封装与解封装
2. 以太网交换、MAC 学习与 ARP
3. IP 子网划分与最长前缀匹配
4. 路由选择与链路代价
5. TCP 握手、滑动窗口与拥塞控制
6. DNS 递归解析与 HTTP 请求链路
7. CSMA/CD 共享介质碰撞与退避
8. 无线信道、带宽、时延和丢包
9. CRC 差错检测与误码定位
10. 停止等待、GBN 与 SR 滑动窗口 ARQ
11. DHCP 地址租约与 NAT 端口映射
12. ICMP Ping 与 Traceroute 路径诊断

## 运行

在本目录执行：

```powershell
node server.js
```

然后访问：

```text
http://127.0.0.1:8899/
```

也可以双击 `start.bat` 启动。

## 操作

- 点击封面打开实验书。
- 左侧切换旗舰实验。
- 播放、暂停、重置控制实验动画。
- 拖动画布移动观察视角，滚轮缩放，一键回正视角。
- 使用参数滑杆精确改变实验条件。
- 鼠标移到画布热点可查看提示，长按热点可打开详细知识点。
- 观察右侧误差监测和实验小手册，按步骤记录参数、指标、异常和解释。
- 点击右上角 `U` 打开大学知识面板。
