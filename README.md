# 高中物理实验书

一个沉浸式高中物理实验 Web 原型。当前版本主打“像一本书打开”的治愈光感体验，并逐步扩展为覆盖高中物理核心实验的交互实验书。

## 当前已完成

- 书本封面开场与黄昏教室视觉氛围
- 多个可切换、可播放、可暂停、可重置的实验
- 参数滑杆与 Canvas 实时物理可视化
- 暂停观察与长按知识点解析
- 理想/现实模式、误差分析与实验小手册
- 桌面与移动端响应式布局
- 后续实验书架占位

## 当前实验

1. 探究加速度与力、质量的关系
2. 探究平抛运动的特点
3. 用单摆测量重力加速度
4. 探究光的折射定律
5. 用双缝干涉测波长
6. 探究感应电流方向
7. 探究弹簧弹力与伸长量的关系
8. 机械能守恒与损耗
9. 伏安法测电阻
10. 探究互成角度两个力的合成
11. 探究气体等温变化规律
12. 测量金属丝电阻率
13. 测定凸透镜焦距

## 运行方式

直接打开 `index.html` 即可。也可以在本目录启动本地服务器：

```powershell
python -m http.server 8878 --bind 127.0.0.1
```

然后访问：

```text
http://localhost:8878/
```
