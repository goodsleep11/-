# 高中物理实验书

一个沉浸式高中物理实验 Web 原型。第一版主打“像一本书打开”的治愈光感体验，深做 5 个旗舰实验，并预留完整实验目录扩展结构。

## 当前已完成

- 书本封面开场与黄昏教室视觉氛围
- 五个可切换、可播放、可暂停、可重置的实验
- 参数滑杆与 Canvas 实时物理可视化
- 暂停观察与长按知识点解析
- 桌面与移动端响应式布局
- 后续实验书架占位

## 五个旗舰实验

1. 探究加速度与力、质量的关系
2. 探究平抛运动的特点
3. 用单摆测量重力加速度
4. 探究折射与干涉条纹
5. 探究感应电流方向

## 运行方式

直接打开 `index.html` 即可。也可以在本目录启动本地服务器：

```powershell
python -m http.server 8878 --bind 127.0.0.1
```

然后访问：

```text
http://localhost:8878/
```
